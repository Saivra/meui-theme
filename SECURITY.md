# Security

Security fixes are provided for the latest `0.1.x` release. Upgrade to the latest patch before reporting
a problem that may already be fixed.

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/saivra/meui-theme/security/advisories/new).
Include affected versions, a minimal reproduction and the security impact. Do not post exploit details,
credentials or customer data in a public issue. Ordinary rendering bugs belong in GitHub issues.

The host application remains responsible for authentication, authorization, tenancy, file access,
validation and data protection. The component studio is disabled by default and requires an explicit
authorization closure when enabled.
